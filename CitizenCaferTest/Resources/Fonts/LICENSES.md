# Bundled fonts

| Family             | Files                                    | Licence                                        |
| ------------------ | ---------------------------------------- | ---------------------------------------------- |
| **Fedra Sans Pro** | `FedraSansPro-Medium/-Bold.ttf`          | Typotheque commercial licence, held by Citizen Café |
| **Assistant**      | `Assistant-Regular/-SemiBold/-Bold.ttf`  | SIL Open Font License 1.1 — see `OFL-Assistant.txt` |

Fedra Sans Pro is **not** redistributable. It ships inside the app binary under Citizen Café's
licence; it must not be re-published, and anyone forking this repo needs their own licence from
Typotheque.

The kit we hold covers Latin, Cyrillic and Greek — no Hebrew. Every Hebrew role therefore uses
Assistant, which is the design bible's Hebrew companion to Fedra anyway. See `BrandTypography`.
